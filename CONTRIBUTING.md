# Contributing to FasFas

Thank you for contributing to FasFas.

Our goal is to build the world's most motivating consistency platform.

---

## Before Writing Code

Ask yourself:

Does this help users become more consistent?

If the answer is no...

Do not build it.

---

## Coding Principles

- Write clean code.
- Prefer reusable components.
- Keep components small.
- Avoid duplication.
- Keep the user experience simple.

---

## Git Workflow

Create a branch.

Build.

Test.

Commit.

Push.

Open a Pull Request.

---

## Remember

Every line of code should support the FasFas mission.

Keep Moving.

Keep Growing.
